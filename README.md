# 南楼求生 · 断水之夜

第一人称末日求生可玩原型。在断供后的旧住宅和南街街区搜索饮水、食物、武器与穿戴；用扳手、棒球棍、猎用弩或手枪对抗感染者，获得经验、分配属性点，再把物资带回安全屋。

保留了原《异常房屋维修员》的厨房、客厅、走廊与冷峻悬疑氛围，现已扩展为东西两翼：原 302、303 加上 304 住户、305 临时医务室、洗衣房与物业库房。现已接入南街：住宅院落、便利店、临时诊所、修车库和背巷。默认入口为求生玩法。

## 开始游戏

在访达中双击 **`开始游戏.command`**，或者在本目录运行：

```bash
./开始游戏.command
```

选择「开始生存 → 出发 · 搜寻物资」。先找 **2 瓶水**，返回公共走廊左端的绿色安全屋门，按 E 撤回入库。饮水不足也允许提前撤回。也可沿公寓走廊向东走到底，对准楼梯门按 **E**。上、下楼有 1.6 秒准备，移动离开或受击会取消；之后短暂加载对应区域。南街北侧南楼入口可原路上楼，再向西回安全屋。场景内不显示文字指引，操作和路线说明可在本文件查阅。

本机已准备好 Godot 4.7.2；另一台 Mac 首次启动时会从官方来源下载同一版本。资源导入完成后进入原生窗口。游玩不需要登录或联网；尚未打包签名的独立发行应用。

| 操作 | 默认按键 |
| --- | --- |
| 移动 / 观察 | WASD / 鼠标 |
| 冲刺 / 蹲行 | Shift / Ctrl |
| 开柜、开门、拿钥匙、上下楼、撤回 | 对准目标按 E |
| 检索柜子 / 尸体 | 按住 E 1.25 秒 / 1.6 秒，完成后点击拿取 |
| 近战轻击 / 远程射击 | 近战短按并松开左键；弩和手枪按下左键发射一发 |
| 重击 | 扳手按住 0.36 秒、球棍 0.55 秒后松开；就绪有轻响 |
| 瞄准 | 持弩或手枪时按住右键 |
| 装填 / 换弹 | R；完成前受击、打开背包或暂停会中断 |
| 推开近身敌人 | V；近战武器也可以用右键 |
| 快速吃喝 | Q |
| 投掷背包里的空瓶 | G |
| 切换主备武器 | 1 或 2 |
| 手电 | F |
| 背包、装备、人物加点 | Tab |
| 暂停 / 释放鼠标 | Esc |
| 保存截图 | F12 |

**近战升级**：安全屋点击「武器升级」，可免费强化已拥有的扳手或棒球棍，背包、装备和仓库内均可操作。升级绑定这件武器并保存；出发时携带的升级装备在死亡返回后保留。扳手升级后，连续短按左键接出「斜击 → 上挑 → 下砸」；球棍升级后，按住左键 0.55 秒再松开，将目标打飞并撞倒后排。受击、暂停、换武器会打断连击。原型阶段不消耗材料；升级没有负面属性取舍。

**探索界面**：已移除路线文字、准星下的物品与操作提示、常驻按键说明和 H 提示功能。可交互目标通过准星变色反馈；保留旋转搜索环、血量、弹药、背包信息及普通门牌和商店招牌。

**背包和检索结果打开时世界继续运行，Esc 才会暂停。** 检索采用准星位置的旋转圆环，中心显示真实完成百分比。检索途中松键、看向别处、离开范围、攻击或受击会中断；拿不下的物品留在原容器。受击会关闭物资列表，回到战斗。 吃喝需要约 1.35 秒，攻击或受击会中断，完成前不会扣掉食物。体力不足时退开恢复，普通移动始终可用。

设置支持视野、灵敏度、亮度、音量、打击镜头回弹、行走晃动、少量血迹开关，以及移动和交互键位调整。默认关闭行走晃动。

## 已实现

- **检索**：公寓 11 个、街区 8 个物资容器和击杀后的尸体都使用有限物资列表。逐件或全部拿取；背包满、半途停止、重复打开和读档不丢失或重复生成物品。主动丢弃改为可检索物资包。
- **搜刮与装备**：瓶装水、罐头、能量棒；扳手、棒球棍、猎用弩、9mm 手枪、弩箭包、9mm 弹药盒、诱敌空瓶；防护外套、运动鞋、登山包。6 格背包，可扩为 8 格；主武器、备用武器、上身、鞋、背包分别装备。
- **人物状态**：生命、体力、饱食、水分，以及饱足、饥饿、缺水、力竭、负伤和能量增益。良好营养支持脱战缓慢回血。
- **近战与反馈**：扳手单手交替短弧、举起下砸；球棍双手横扫、重蓄力斜劈。分别设置接触帧、收招、碰撞宽度、音色、命中停顿、镜头回弹和击退。材质对应木屑、火星、玻璃碎片、粉尘和少量血粒；墙壁阻挡攻击。空瓶有独立举臂投掷动作，在松手出瓶时扣除物品，起手被打断不丢瓶子。
- **第一人称手部**：替换球体手掌和圆柱手臂，使用带 26 根骨骼的左右手、露指手套、皮肤与织物贴图；近战紧握、枪械扣扳机姿势、弩托举、手电握持和投掷张手分别适配。袖子有前臂锥度、布料褶皱和收口。手部资源采用 CC0 许可，编辑源文件为 `art/first_person_hands.blend`。
- **近战质变升级**：安全屋为单件武器升级。扳手「破势」提供三段连击、上挑与下砸追击，并支持一次点击缓冲；球棍「破阵」重击能击飞真实敌人身体，撞倒路径中的后排，墙体会阻挡飞行。球棍基础轻击也可命中身前多个可见目标。升级外观增加金属箍或握把缠带；加入重击与落地音效，升级近战直接击杀回复少量体力。飞行、倒地、已碰撞目标及武器升级随存档和区域保留，尸体落地后仍须检索。
- **远程战斗**：猎用弩逐发装填 1.85 秒，弩箭有飞行时间与下坠，射击声较小；9mm 手枪使用 8 发弹匣，1.45 秒换弹，逐次点击发射，有枪口闪光、套筒回退与镜头后坐力。远程要害命中增加伤害，墙体和枪口前遮挡会挡住射击；枪声会吸引更远的感染者。右键瞄准、R 装填，V 仍可推开敌人。
- **弹药与回收**：武器搜到时为空仓，弩箭每包默认 6 发、手枪弹药每盒 12 发，各占背包一格；装填完成时才从对应弹药包扣除，部分用过的包保留余量。命中感染者的弩箭在其死亡后进入尸体物资列表，必须搜尸领取；未命中的弩箭不回收。弹仓、弹药余量及飞行中的箭都随区域和存档保留。
- **感染者**：替换为 Pixelhouse 有贴图、有骨骼的模型；Walk / Attack / Death 三套动画、3 种衣色与体型变体。公寓 7 个、街区 8 个敌人，视线发现、调查声音、追击、攻击预备、收招、受击与死亡。脚步、战斗和投瓶影响调查位置，墙与门影响声音。
- **成长**：普通击杀 40 经验，第三次击杀可升到 2 级；首版上限 5 级。每级 1 点，可提升力量、体质、耐力、敏捷；安全屋可重置。
- **地图与交互**：新增东翼走廊、304、305 临时医务室、洗衣房和物业库房，地面覆盖约为原来的 2.17 倍。303 后侧通往洗衣房，304 与医务室之间有墙洞，形成两条绕行路线。厨房下柜、客厅门、304 门、物业门及可破坏玻璃柜均可交互。
- **南街探索**：约 52 × 44 米的首个街区场地，包含院落、主街、便利店、临时诊所、修车库与外围背巷。三处商店前后贯通，可以绕行；废弃车辆、路障、雨后积水、路灯与双向路牌提供定位。场地尺寸包括建筑占地，并非净可行走面积。
- **区域加载**：公寓与街区通过楼梯入口分区切换，后台加载资源后实例化；只保留当前区域的场景、碰撞和敌人。街区内 26 米外的感染者暂停模拟。区域往返保留柜门、尸体、敌人生命和剩余物资，同一次外出中不会因加载重新生成。
- **完整外出循环**：带回物资入库，整理装备后再次出发；死亡保留成长和仓库，恢复出发前装备，丢失本轮背包物资和新穿戴。
- **保存**：每 3 秒、重要交互、暂停和正常退出自动保存；继续游戏恢复同一次外出中的物资、敌人、柜门和奖励记录。

## 当前范围

这是可游玩的住宅与街区探索原型，包含两块区域、一种感染者的外观变体、固定物资和确定的尸体检索内容。街区内自由行走，上下楼采用短暂加载；尚未实现连续可行走的多层楼梯或整座城市的无缝流式加载。暂未加入随机地图、其他枪械类型、制作、联机和基地建造。

世界状态的保留范围是**同一次外出及其存档续玩**。撤回后再次「出发」或死亡后重新出发，沿用原玩法重新布置遭遇和物资；切换区域不会重置。诊所目前提供已有的饮食恢复物资与穿戴，尚未引入独立药品系统。

美术仍是基础模型与氛围原型，场景、第一人称手臂和动作仍需精修，**尚未达到已选写实概念图的精度**。当前的击打反馈和 AI 可用于验证玩法，但还需要玩家试玩调整节奏、难度和声音质感。

## 构建与验证

已生成资源可直接运行。如需从脚本重建全部资产：

```bash
bash tools/build_assets.sh
```

构建会覆盖相应 `.blend` 和 `.glb`，在 Blender 中手改之前请另存副本。使用 Blender 5.2.1 LTS 与 Python 3，无需 Python 第三方包；可用 `BLENDER_EXECUTABLE` 指定路径。

```bash
bash tools/test.sh
```

包含求生状态、实际物理场景、远程与近战升级集成测试，同时保留旧维修测试。测试使用独立存档，不改写正常游玩进度。

实际游戏画面截图（先建立输出目录）：

```bash
mkdir -p artifacts/survival
./开始游戏.command -- --view=kitchen --capture="$PWD/artifacts/survival/kitchen.png"
```

拍摄视角支持 `kitchen`、`combat`、`bat`、`corpse`、`search`、`storage`、`inventory`、`base`、`credits`、`east`、`laundry`、`aid`、`loading`、`district`、`market`、`clinic`、`garage`、`crossbow`、`pistol`；使用实际 3D 场景，冻结现场并跳过存档。正常游玩请不加拍摄参数。

## 存档

macOS 数据目录：`~/Library/Application Support/Godot/app_userdata/南楼求生/`。

- `south-block-survival-v3.json`：角色、仓库、本次外出进度、检索状态与剩余物资。地图修订号现为 2；旧地图存档会补充一次东翼内容，原区域已取物资与击杀记录保持原样。新增 `region` 与 `regions` 字段保存当前区域和未加载区域；旧档缺少区域字段时默认为公寓，首次下楼生成街区内容，无需重开。远程装备修订号 `ranged_revision=1`：旧区域首次加载时向指定容器补入一次新装备和弹药，原有物资与搜索状态保持；此后不会重复补入。
- `south-block-survival-v2.json`：上一版进度。如果还没有 v3 存档，会读取并转换该档，原 v2 文件保留。已拿走/消耗的物品不会重新生成。
- `south-block-settings-v2.json`：设置。
- `survival-screenshot.png`：F12 截图。

「重新开始」经过游戏内确认后替换求生档。旧维修档仍在 `异常房屋维修员 · 302` 用户数据目录，不会自动迁移或覆盖。
