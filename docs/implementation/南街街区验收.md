# 南街街区 · 首版验收

日期：2026-09-16。

## 已交付的游玩流程

公寓东翼尽头的楼梯门按 E → 准备 1.6 秒 → 载入南街 → 院落、便利店、诊所、修车库或背巷搜索 → 北侧南楼入口上楼 → 沿走廊向西返回绿色安全屋门 → 饮水和物资入库。

准备期间离开入口、攻击或受击会中断。资源加载期间暂停模拟并显示旋转提示，完成后恢复操作。区域切换本身不会恢复人物生命、清空背包、发放经验或刷新物资。

## 内容与布局

- 新街区地面场地 52 × 44 米，尺寸包含建筑占地；场地边界有实体围墙与封路设施。
- 8 名感染者，继续使用带 Walk / Attack / Death 的 Pixelhouse 模型，按角色 ID 分配三种已有外观。
- 8 个有限物资点：院落应急箱、便利店货架与后仓、诊所应急箱与背包、修车库工具箱与工作柜、背巷行李箱。共 20 件初始物资，必须检索后领取。
- 三处店面各有前后入口，外围背巷接回主街；能绕行、从后门接近物资点。
- 复用已有饮食、装备、近战和成长系统。诊所当前提供饮食恢复物资与穿戴，没有新增独立药品机制。
- 阴天冷光、雨后积水、路灯、路牌、废弃车辆、卷帘和街道排水设施。美术仍为可玩原型，未达到写实概念图精度。

## 区域与存档

`world.gd` 仅挂载当前区域的建筑、碰撞、灯光与交互。进入楼梯时通过后台请求载入目标 GLB，准备就绪后在主线程实例化；这一步仍可能产生短暂帧耗时，不宣称无卡顿或整座城市无缝流式加载。

卸载前把敌人、尸体、容器及柜门序列化，返回时恢复。未加载区域没有运行中的敌人节点；街区内 26 米之外的存活感染者暂停模拟。各区域使用独立寻路网格；障碍物按覆盖格子写入，避免逐格遍历所有建筑。

当前公寓与街区各自为单层行走空间，通过楼梯切换相连。暂未增加可连续行走的多层楼梯或 3D 导航网格。

继续使用 v3 求生档和公寓地图修订号 2，新增 `region` 和 `regions` 字段。旧档没有区域字段时默认为公寓；首次进入南街才生成其物资。同一次外出中来回切换和退出续玩均保留状态。撤回或死亡后再次「出发」沿用原有规则，开始新的遭遇和物资布置。

## 验证

原有 761 项检查全部通过，新增街区集成检查 136 项通过，合计 897 项。正常时间步运行，无脚本错误、失败或资源退出错误。另已通过区域生命周期冒烟检查：在街区重新开始，以及街区死亡后重新出发，均回到公寓并保留亮度设置、恢复室内环境声。

新增检查使用真实物理场景与选择射线，包含：

- 从公寓走到楼梯入口，受击取消准备，后台加载并冻结／恢复操作。
- 沿前后门、街道及背巷实走，逐一检索全部 8 个物资点。
- 户外物资按唯一 ID 转移；部分领取后往返、存档续玩不重复。
- 区域卸载后原公寓敌人、搜索结果、已打开的门准确恢复。
- 感染者死亡变为可检索尸体，往返后不重复发放经验。
- 街区位置不被旧公寓边界截断；附近丧尸追踪攻击，远处暂停模拟。
- 街区两瓶饮水带回原安全屋，入库并完成目标。
- 新一次出发清空上一轮区域记录，旧无区域字段存档兼容。

本机原生 Metal 渲染截图：`artifacts/survival/district.png`、`market.png`、`garage.png`。截图使用真实场景冻结视角，跳过游玩存档写入；截图时帧率不作为动态实战性能基准。

早期快速检查使用 `--fixed-fps` 加速模拟，退出前音频线程来不及清理，产生过音频资源警告；正式验收采用正常时间步并确认无此错误。
