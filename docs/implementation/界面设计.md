# 302 原型界面基准

主体：空置住宅的维修工单。界面的工作是提供可靠读数、明确操作与验收依据。

颜色沿用视觉基准：蓝灰 #27343B、灰绿 #667875、纸张灰白 #B7BDB6、标记锈红 #92574C、检修灯暗琥珀 #C99A53。

字形：标题用系统宋体，正文用系统黑体，仪表数字用等宽字体；不复制或分发系统字体文件。

布局：主菜单左侧窄幅标题和工单入口，右侧保留实时厨房；游戏视野只保留小准星、底部交互与短反馈；完整验收项收进 Tab 工单。

标志性元素：旧纸工单和会实时变化的实体表针。工单上的勾选必须来自真实修理与复测状态。

自查：不增加与维修无关的数据卡片；不让菜单装饰占据异常现场；菜单层级、键盘焦点与操作提示保持清楚。
