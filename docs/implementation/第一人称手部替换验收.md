# 第一人称手部模型替换

日期：2026-09-16。

## 替换结果

原有球体手掌、几何手指和直筒手臂已替换。当前使用 Godot XR Tools 的左右手模型，每只手有 2,158 个顶点、3,490 个三角形和 26 根骨骼。材质包含深色露指手套、皮肤、指甲，以及颜色、法线、AO/粗糙度/金属度贴图；左右手与手电握持使用各自的骨骼实例，纹理共享。

袖子由本项目在 Blender 中制作，包含椭圆前臂轮廓、腕部收窄、布料褶皱和袖口，运行时接到手腕骨骼位置。模型保留为 `art/first_person_hands.blend`，贴图已打包。

## 握持与动作

- 扳手、球棍紧握握柄，球棍副手使用左手模型。
- 手枪与弩的主手采用扣扳机姿势，副手分别握持枪柄与托举弩身；装填时沿原有动作移动。
- 手电由独立左手持握，并调整发光位置，避免光源从手部后方把指尖照得过曝。
- 投瓶准备与出手使用不同手势；推开时张手。
- 调整第一人称待机距离和高度，使手掌、袖口与握点可见。攻击时机、伤害、体力、弹药及升级数据保持原规则；没有新增场景文字提示。

只引入美术资源，不需要 VR 设备或 XR 插件。运行时保留源 glTF 的关节坐标，使作者手势与骨骼兼容。Blender 源文件和袖子可重新生成：

```bash
/Applications/Blender.app/Contents/MacOS/Blender --background --disable-autoexec --python tools/import_hands.py
```

## 验证

Godot 资源导入无脚本错误。以下四组既有测试共 **308 项断言、0 失败**：实际求生场景 149、检索与挥击 57、远程武器 59、近战升级 43。日志为 `artifacts/survival/hands-regression.log`。

原生 Metal 实机检查四种武器、两种瞄准、两种装填和投瓶前后，共十个视角。截图位于 `artifacts/survival/hands-*.png`。复现命令：

```bash
.tools/Godot.app/Contents/MacOS/Godot --path game --script "$PWD/tools/capture_hands.gd"
```

截图脚本使用独立存档，不修改正常游玩进度；也检查主手和两种副手的左右骨骼是否正确。

当前采用作者手势与既有武器轨迹结合，尚无根据任意物体表面自动计算逐指接触的系统。后续更換武器模型时仍需调整对应握点。
