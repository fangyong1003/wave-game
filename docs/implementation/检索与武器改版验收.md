# 《南楼求生》检索、武器与丧尸改版验收

日期：2026-09-14。对应反馈：丰富丧尸模型；区分各武器的动作与打击感；取消直接物资掉落，改为检索尸体或容器。

## 已实现

### 丧尸资源与动画

实际采用 [Zombie — Pixelhouse](https://opengameart.org/content/zombie)，许可 [CC BY 3.0](https://creativecommons.org/licenses/by/3.0/)。已经下载并转换为可编辑 Blender 文件和离线 GLB，不需要游玩时下载。源网格 1,810 个顶点、3,573 个三角形，使用漫反射和法线贴图。

导入了 Walk、Attack、Death 三段骨骼动画，连接追击、攻击预备与收招、受击、死亡状态。修正朝向和比例，避免模型背对追击方向。尸体检索区跟随骨盆的位置，倒地后不会留在半空。3 个场景敌人采用同一基础模型的颜色和体型变体，并非三套独立人物模型或新敌人职业。

来源包位于 `art/external/pixelhouse_zombie/`；编辑源为 `art/pixelhouse_zombie.blend`。`tools/import_zombie.py` 可重建，`tools/build_assets.sh` 已包含该步骤。署名保存在 `game/licenses/Pixelhouse-Zombie-CC-BY-3.0.md` 及游戏主菜单「制作与资源署名」。

### 武器动作与反馈

| 武器 | 轻击 | 重击 | 蓄力阈值 | 命中时刻，轻 / 重 | 动作总时长，轻 / 重 |
| --- | --- | --- | --- | --- | --- |
| 扳手 | 单手、左右交替短弧敲击 | 举起后向下砸 | 0.36 秒 | 0.12 / 0.22 秒 | 0.52 / 0.78 秒 |
| 球棍 | 双手、交替大幅横扫 | 较长起手、斜向下劈 | 0.55 秒 | 0.25 / 0.38 秒 | 0.85 / 1.12 秒 |

总时长从松键开始计算，不包含按住蓄力和命中停顿。蓄力就绪有轻响提示。球棍使用双手持握，手电改为胸前照明；手臂随握点连接。两种武器分别使用轻重动作轨迹、接触帧、恢复窗口、碰撞宽度、破风音和接触音层。

扳手命中停顿为轻击 28ms、重击 56ms；球棍为 60ms / 92ms。球棍镜头回弹与击退更强，轻击带横向击退。命中表面继续决定木屑、火星、玻璃碎片、粉尘或血粒。保持一次挥击至多伤害一次，墙体阻挡攻击，体力不足不能发动。

空瓶使用独立举臂投掷，0.24 秒松手时扣除背包物品并生成投射物，随后回收手臂。起手受击、暂停或打开背包会中断，尚未抛出的瓶子不会消失。出瓶位置先检测近处墙体，避免投射物生成在墙后。

### 检索与有限库存

- 初始物资收纳在厨房补给箱、厨房下柜、玄关工具箱、303 储物架和玻璃柜，共 5 处。
- 对准并按住 E 检索：普通容器 1.25 秒，尸体 1.6 秒。柜门需要先打开，玻璃柜仍可找钥匙或砸开。
- 松键、看向别处、走远、攻击、受击或打开其他菜单会中断，物资不被扣除或自动领取。
- 完成后右侧展示物资清单，逐件或全部拿取。背包已满时禁用领取按钮；剩余物资继续保留在原处。
- 已检索容器再次交互直接打开结果；搜空后保持空，同一次外出内不会因重开面板或读档刷新。
- 击杀即时发经验，装备与食物留在尸体中。重复死亡回调不重复发经验或创建第二份物资。
- 主动丢弃物品会形成可检索的物资包。
- 检索面板打开时世界继续运行，受击会关闭面板。Esc 暂停。钥匙是单独的关卡交互，不占物资背包。

新快照版本为 3，记录每个来源的剩余物品、检索状态及尸体关联。支持读取旧版 v2，将尚未领取的散落物迁移进对应柜子、尸体或遗留包；不会重新填满空容器，也不会复制已拥有或已消耗的物品。自动迁移写入 v3，保留原 v2 文件。

## 验证结果

`bash tools/test.sh`：**657 项检查，0 失败，无脚本或引擎错误输出**。

| 测试 | 检查数 |
| --- | ---: |
| 原维修状态回归 | 317 |
| 原维修场景回归 | 53 |
| 求生人物与物资状态 | 81 |
| 求生实际物理场景 | 149 |

新增覆盖包括：未检索不能领取、各类中断、容量不足和部分领取、重复领取、空来源不刷新、遮挡禁止远程领取、击杀与尸体奖励去重、读档保留检索结果、v2 精确迁移；两种近战武器不同的动作和接触时间、恢复保护、体力消耗；投瓶起手中断与单次出瓶。模型检查涵盖贴图、动画、骨骼高度以及各段动画中骨盆与角色的距离。

更新动作过渡后，再次通过 149 项场景检查；57 项检索和武器检查另外使用本机 Metal 渲染运行，0 失败。测试使用隔离存档，不写正常游玩进度。

## 试玩入口与范围

双击项目根目录的 `开始游戏.command`，已有游戏窗口需退出后重新启动。进入厨房后，对准台面补给箱按住 E，拿取饮水；击败客厅感染者后检索尸体获取球棍，Tab 装备或放入备用槽再切换。

当前仍是一张小地图、3 个感染者的可玩原型。采用的是带贴图的低模写实角色，环境、第一人称手部和衣料尚未达到概念图的精度；没有在本轮加入枪械、新敌人种类或扩展关卡。动作与音效已经可用于试玩比较，最终节奏和难度仍需要实际玩家反馈。
