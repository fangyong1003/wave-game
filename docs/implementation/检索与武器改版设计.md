# 检索与武器改版

依据 2026-09-14 的新反馈，资源必须经过检索，不再在击杀时散落成可拾取物。

## 操作与界面

按住 E 检索 1.25 秒，尸体为 1.6 秒。松键、看向别处、离开范围、攻击、受伤或打开其他菜单会中断，不揭示内容。完成后显示物资列表，逐件领取或全部拿取；容量不足的物品保留在原容器。已检索但没拿完的目标再次交互直接打开列表。搜索过的空容器保持空，重复搜索、读档不重新生成物资。

厨房台面改为补给箱、下柜保留开门后检索；玄关工具箱、303 储物架和玻璃柜均使用同一检索规则。死亡感染者成为可检索尸体，经验在击杀时发放，装备和食物在检索后领取。玩家主动丢弃的物品打包留在原地。

沿用现有灰绿住宅界面：背景 #202d2d、文本 #d4d8d0、次要信息 #98a9a4、可操作提示 #c99a53、生命 #aa6253。宋体标题、苹方正文、Menlo 数值。检索结果面板靠右，占约三分之一视野，左侧保留现场与生命条；标题是具体的尸体或柜子名称，紧邻显示背包容量。现场继续运行，Esc 可暂停，受伤会关闭面板并回到战斗。

相比现有全屏整备页，右侧物资面板让玩家查看结果时仍能观察威胁。这个布局变化对应搜刮的风险，不新增与玩法无关的装饰。

## 武器动作

扳手采用单手短弧，轻击左右交替，重击为举起后向下砸；接触早、收招短，金属回弹利落。球棍采用双手横扫，重击更高蓄势并斜向下压；接触稍晚、扫幅更宽、回收更慢，沉闷冲击与失衡更明显。区分持握姿态、起手、轨迹、接触时间、恢复时间、音色、镜头回弹和命中停顿，不仅调整伤害数值。

空瓶使用独立的举臂投掷动作，0.24 秒松手时扣除物品并生成投射物；起手被打断时仍在背包，左手退让、主武器暂时收起。碰撞和伤害在各自有效接触时段发生；墙体优先阻挡后方目标，连续有效帧不会重复奖励。

## 存档

使用版本 3 的世界快照，保留人物状态版本 2。保存容器内容、检索状态和尸体关联；兼容转换版本 2 的散落物及已领取记录。迁移写入新的求生档，原档作为回退保留，不重置等级、仓库或装备。
