# 近战质变升级首轮验收

日期：2026-09-16。范围：棒球棍「破阵」、扳手「破势」及安全屋升级入口。

## 实际玩法

安全屋的「武器升级」列出已经拥有的扳手和棒球棍，包括主备装备、背包及仓库。点击即可强化该件物品，已升级的按钮禁用。原型阶段免费，不新增材料、货币或属性惩罚；也不会直接赠送武器。球棍继续通过检索取得。

| 武器 | 操作 | 升级后的结果 |
| --- | --- | --- |
| 棒球棍 · 破阵 | 左键按住至少 0.55 秒再松开 | 重击 108 基础伤害，可直接解决现有 95 血普通感染者；身体沿攻击方向飞出，撞中后排造成 62 伤害并击倒约 1.5 秒。飞行被墙挡住；若目标仍存活，首次强烈撞墙追加 38 伤害。 |
| 旧扳手 · 破势 | 连续短按左键，保持目标在攻击范围 | 斜击 34 → 上挑 34 → 下砸 84。第二击让敌人离地，第三击追击并砸向地面；普通目标可以在一套连击内击杀。 |

伤害随已有力量属性增长。扳手每段消耗 14 体力，球棍重击仍消耗 35；升级近战直接击杀返还 8 点体力，不超过上限。球棍轻击的多目标横扫属于基础质量修正，未升级版本也获得；目标必须位于范围内且不被墙体或前排身体遮挡。

扳手允许提前缓冲一次点击，接触与随挥完成后衔接下一段。成功命中提供 1.05 秒续段窗口；挥空、受击、换武器、推开、投瓶或暂停会终止连段。原有蓄力重击仍保留，不能通过连点越过首次接触时机。

## 反馈与一致性

- 球棍增加金属箍和握把缠带，扳手增加包带；同型号不同实例切换时刷新外观与能力。
- 上挑、下砸使用独立手部轨迹；重击、接触停顿、镜头回弹、材质粒子和音色分别配置。新增项目内合成的重击、落地声音。
- 击飞通过真实世界碰撞移动角色，沿实际移动路径检查后排碰撞；同一飞行对每个目标仅结算一次。撞墙后不继续隔墙伤害。
- 不新增场景文字操作提示。说明位于安全屋管理页和本文件；战斗沿用现有准星、命中反馈和状态界面。
- 击杀仍创建可检索尸体，不直接散落物资。检索位置随身体移动，落地和墙边有可达性处理；奖励不会因碰撞、落地或读档重复发放。
- 物品新增可选布尔字段 `melee_upgrade`。旧档未提供该字段时视为未升级；无效字段拒绝恢复。升级随物品转移和保存，出发前已装备的升级武器依照原死亡规则保留。
- 敌人保存飞行速度、方向、剩余时间、碰撞目标记录和倒地进度；保存/载入或区域返回不会重复结算后排碰撞。速度与方向不使用世界坐标边界裁剪。

## 验证

本轮完整回归通过：9 组测试共 **999 项断言，0 失败**，其中新增近战升级 43 项。Godot 导入与运行日志无脚本错误；原生 Metal 实机输出 10 张截图，已检查升级页、基础入口、武器外观、上挑、下砸与击飞落地画面。

自动化命令：`bash tools/test.sh`。专用测试为 `tests/test_melee_upgrades.gd`，覆盖升级权限、重复/伪造请求、旧存档兼容、死亡保留、管理页操作、球棍多目标、墙体遮挡、击飞连锁、空中读档、尸体位置、奖励幂等、扳手三段连击和受击/暂停取消。使用独立测试存档，不改动玩家进度。

实机截图命令（Godot 原生 Metal 渲染）：

```bash
.tools/Godot.app/Contents/MacOS/Godot --path game --script "$PWD/tools/capture_melee.gd"
```

输出到 `artifacts/survival/melee-*.png`，包括安全屋、升级页、武器外观、击飞、后排倒地、上挑、下砸与落地状态。拍摄脚本使用独立存档。

## 目前边界

本轮采用受控击飞与已有骨骼动画组合，不是完整布娃娃。手臂、角色落地及起身过渡仍是原型精度，手感需要玩家实际试玩后继续调整。未实现后续分支树、材料消耗、突进、横扫连段、其他装备强化或新敌人类型。
