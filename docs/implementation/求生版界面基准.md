# 求生版界面基准

沿用已确认的冷峻写实住宅风格。界面像住户在封锁后整理的携行记录；深灰绿 `#202d2d`、雾灰 `#d4d8d0`、旧纸 `#b7bdb0`、血条暗红 `#aa6253`、体力灰绿 `#a7b9a0`、提醒琥珀 `#c99a53`。

宋体负责“南楼求生”标题，黑体负责背包和操作，等宽字体负责等级与读数。战斗视野只保留角落生命体力、饮水目标、小准星和短暂命中反馈。

背包展开成三栏：分类物资、身体装备、人物属性。物品不使用与题材无关的宝石品质色；通过名称、实际外观和装备增减值判断用途。安全屋用同一套物资界面展示仓库和出发准备，减少记忆负担。

标志性元素是随实际携带内容变化的六格背包，以及旁边直接显示的四项机能加点。升级只给短提示，玩家自行决定何时分配；背包不暂停现场，Esc 明确暂停。

自查：保留现场视野与声音，不以大范围炫光遮挡敌人动作；每个按钮只表达一个实际可执行的动作。对比、容量不足和无法卸下背包都必须解释原因。开发后使用原生截图检查菜单、战斗 HUD、背包和结算。
