# 东翼扩图与旋转检索

日期：2026-09-14。依据本次反馈，将搜索 loading 改为旋转形式，同时扩展可游玩地图。

## 实际变化

检索时，原横向进度条替换为准星位置的旋转圆环，中央显示真实完成百分比。光弧持续旋转，深色底保证在亮色柜子前也能看清。松键、转头离开目标、走远、攻击、受击和打开菜单会取消；完成后圆环消失、显示物资清单。食用、撤离和武器蓄力保持各自原有提示，蓄力条的阈值与当前武器一致。

地图向东扩展，地面平面覆盖从约 102.18 平方米增加至 221.86 平方米，约为原来的 **2.17 倍**。该数字按物理地板矩形的并集计算，包含墙和家具占地，不是扣除障碍后的净通行面积。

| 区域 | 场景内容 | 新增物资位置 |
| --- | --- | --- |
| 东翼走廊 | 连续地板、照明、房号与返回安全屋路标 | 连通各房间 |
| 304 住户 | 可开关入户门、沙发、餐桌、窗户、橱柜及遗留行李 | 食品箱、行李箱 |

| 物业库房 | 向室内开的门、工作台、置物架和储备箱 | 工具箱、应急储备 |

新增 4 个感染者、6 个容器，合计 **7 个感染者、11 个初始物资容器**。新区域的物资继续分为可食用、武器和穿戴，都需检索领取。怪物击杀经验、尸体检索和背包规则沿用上一版。

形成两条可实走的回路：

- 公共走廊 → 东翼 → 洗衣房 → 303 后侧通道 → 原走廊。
- 东翼 → 304 入户门 → 墙洞 → 临时医务室 → 东翼。

仍然是带回两瓶水即可撤回安全屋，向东深入可自行选择。原 302、303 和安全屋的位置保持不变。

## 导航与保存

Blender 构建导出统一的可编辑模型和碰撞数据。导航范围不再硬编码为旧地图大小，而是根据真实地板并集和障碍自动构建。门开关后同步更新路径，缺失地面的旧地图凹口和新地图外围不能进入。读档位置限制同样根据当前地图边界计算，东翼位置不会被挤回旧地图边缘。

沿用世界快照版本 3，新增 `map_revision: 2`。旧版 v2 和缺少地图修订号的 v3 存档会补充一次东翼敌人与物资；旧区域已检索、已搜空、已消耗、已击杀和角色成长记录继续保留。新版存档再次读取时不刷新东翼内容。安全屋状态下升级会在下次正常出发时进入完整新地图。

## 验证

验证结果：原有回归 **657 项通过**，新增扩图测试 **104 项通过**，合计 **761 项通过**。没有脚本或引擎错误输出。原生 Metal 场景截图完成视觉检查，跨区域 AI 实测进入 303 后对玩家造成伤害。

运行 `bash tools/test.sh`。新增 `tests/test_east_wing.gd`，覆盖真实移动穿过两条回路、全部新增容器的射线选中与检索、圆环旋转与完成度、开门后的路径更新、东翼位置和库存读档、携带新区域饮水返回原安全屋、跨区域敌人追击及地图升级只执行一次。

测试使用隔离存档。实际 Metal 渲染截图位于 `artifacts/survival/`：

## 运行与开发

重新运行根目录的 `开始游戏.command`，从原走廊向东进入新增区域；也可从 303 后侧进入洗衣房。旧存档无需重开。

地图编辑源：`art/south_block_survival.blend`。东翼构建源：`tools/build_east_wing.py`，由 `tools/build_survival_assets.py` 调用。运行 `bash tools/build_assets.sh` 可重建全部资产；已生成的 GLB 可直接游玩，无需安装新运行库或联网获取素材。

本轮扩展仍为单层住宅玩法原型，没有增加楼梯、多楼层或新物品类别。全部新增场景道具在项目内制作，继续使用已有授权材质和感染者模型。
