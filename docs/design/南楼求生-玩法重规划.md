# 《南楼求生》玩法重规划

> 2026-09-14 改版已实装：尸体和柜子需按住 E 检索后领取；取消自动掉落。武器改为独立持握、动作与打击反馈。当前实现与数值以 `../implementation/检索与武器改版验收.md` 为准；下文未标为已实现的内容仍是设计方向。

版本：v0.2  
日期：2026-09-14  
状态：用户已授权开发，首个求生版本已实现。本稿保留完整设计方向；实际交付及暂缓细节以 [首版验收](../implementation/南楼求生-首版验收.md) 为准，当前启动入口已切换为求生模式。

## 1. 已确认的方向与本稿建议

用户反馈：“维修有一点无聊”，希望保留已有基础，改为搜索物资、增加打击特效的末日求生类型。

本轮进一步明确：物资分为可食用、武器、穿戴三大类；人物增加血量与状态；通过打怪获得经验、升级并提升机能素质。以下已将这些要求纳入核心玩法。

沿用已确认的第一人称、冷峻悬疑和写实旧住宅风格。复用公寓、走廊、扳手、灯光材质、移动交互与设置基础。

本稿建议采用单人、近战为主、每次短途搜刮后撤回安全屋的结构。暂名《南楼求生》；感染者题材、背包容量、敌人数与各项数值均为待试玩验证的设计起点，不视为用户已逐项确认。

## 2. 玩家在做什么

城市断供后的第七天，你躲在南楼一间临时安全屋。饮水即将耗尽，附近住户已失去联系。你带着旧扳手和手电，进入楼上的住宅寻找补给。

**核心循环：整备角色 → 搜刮食物、武器和穿戴 → 战斗获得经验 → 检索尸体领取物资 → 升级加点、调整装备 → 继续深入或撤回入库。**

关键选择是：现在的收获已经有用了，是否值得冒险再打开一个柜子？

每次外出需要出现四种满足感：找到有用物资、用扎实的攻击击败敌人、升级后感到能力提升、把收获带回来。搜刮提供补给和装备，战斗同时提供经验，撤离把临时收获变成长期储备。

躲避能节省消耗，主动战斗能获得更多成长；路线里同时安排低风险补给点和值得挑战的装备点。让玩家有理由主动接战，也保留受伤撤回的选择。

原先的重复测量、阀门顺序与复测验收退出主循环。维修身份可以保留为背景；撬柜、破障一类动作只承担短促的探索交互，不再发展为管线解谜。

## 3. 搜刮：让物资位置和取舍有意义

### 寻找具体的东西

- 厨房更容易找到瓶装水、罐头；玄关和工具柜可能有武器；衣柜、鞋柜与行李箱可能有穿戴装备。
- 走近后才能辨认具体物品，准星对准时出现名称和拾取键。不开全屋透视，也不让所有资源远距离发光。
- 柜门打开后直接看到里面的东西，按 E 取走。普通搜刮没有反复读进度条的等待。
- 物品离开原位置、柜门保持开启，帮助玩家记住搜过哪里。
- 值钱位置有可信线索，例如柜上饮水箱标识、工具包装、衣柜和门后的搬运痕迹。

### 三类取得方式

| 容器 | 交互 | 玩家付出的代价 |
| --- | --- | --- |
| 敞开的货架、桌面 | 直接拿取 | 需要看见并走到物品前 |
| 普通抽屉、柜门 | 一次打开，逐件取物 | 发出轻微、近距离可听见的声音 |
| 卡死柜门、玻璃储物柜 | 找钥匙安静打开，或用武器破开 | 武力较快，但响声会吸引附近敌人 |

首版只选一个高价值柜实现“安静绕路找钥匙 / 直接砸开”的分支，避免每个容器都需要解锁步骤。钥匙属于任务物件，不挤占补给格。

### 三大物资类别

| 类别 | 首版例子 | 核心用途与差异 |
| --- | --- | --- |
| 可食用 | 瓶装水、罐头、能量棒 | 水补充水分，罐头提高饱食，能量棒提供饱食与短时体力恢复增益；良好营养状态支持脱战缓慢回血 |
| 武器 | 扳手、棒球棍、可投掷空瓶 | 扳手偏均衡；棒球棍更长、重击更强但耗体力更多；空瓶主要用于投掷诱敌 |
| 穿戴类 | 防护外套、运动鞋、登山包 | 外套增加防护；鞋影响移动或抗失衡；背包扩充携带格数 |

分类边界：可食用包括食物与饮品；投掷器具归武器。绷带不属于食物，本版先移出掉落池，流血、感染及其完整治疗系统留待后续设计。手电作为固定工具，首版取消独立电池消耗与电池掉落。钥匙等关卡物件进入任务记录，不占用三类补给背包。

### 物品要能改变下一次行动

- **食物**：使用后直接改变饱食、水分或短时增益，不只是撤离分数。进食需要短动作，攻击、受击或取消会中断；动作成功完成时才消耗物品并结算效果。同名增益刷新持续时间、不叠加倍率；进食不会瞬间回满血。
- **武器**：显示伤害、攻击距离、出手节奏、体力消耗和失衡效果。武器特点优先于单一评分：短促灵活与长距离重击都应有用途。首版做固定武器数据，暂不增加随机词条和耐久维修。
- **穿戴**：显示防护、移动、体力或容量变化。厚外套可以用更高防护交换更高冲刺消耗；运动鞋偏机动，工靴与其他抗性装备后续增加。属性页明确显示装备带来的增减。
- **来源**：房间提供大部分可食用物和基础穿戴，击败敌人提供经验并有机会掉落武器、穿戴或随身补给。首关至少安排一次确定的装备收获，不能完全依赖随机概率。

### 背包与装备槽

基础携带容量为 6 格，登山包可提高到 8 格作为首版升级示例；每件未装备物品占 1 格，不加入物品旋转或重量模拟。

装备槽先做：主武器、备用武器、上身、鞋、背包。已装备物品不占携带格；替换下来的装备需要放回背包，容量不足时让玩家明确选择丢弃或取消。换成更小的背包前先处理超出的物品，不能静默删除。手套、头部与饰品槽后续扩展。

打开背包时世界继续运行，允许快速使用、穿戴、丢弃或替换；Esc 提供单人暂停。界面分为“三类物资列表 / 当前装备 / 人物属性”，对比新旧装备时标出具体变化。经验条和临时状态也可在人物页查看。

关键物资有保底，随机只改变额外收获和部分摆放。首关的两瓶撤离用水另有一份备用饮水，避免正常饮用就耗尽任务物资；消耗过多仍可提前撤回，不封锁出口。钥匙不会出现在自己锁住的柜里，搜索过的柜子在本次外出中不刷新。

## 4. 近战：扳手有重量，命中能改变局面

第一把武器继续使用现有扳手。战斗围绕距离、挥击时机、推开和门口位置展开。先把扳手的手感做好，再加入棒球棍，用两把有差异的武器验证掉落与换装；枪械与复杂连招后续再做。

| 动作 | 建议输入 | 作用 |
| --- | --- | --- |
| 轻击 | 短按左键 | 起手快、消耗少，用于抓住敌人攻击后的空当 |
| 蓄力重击 | 按住左键后释放 | 起手更慢，造成更强硬直；松开过早按轻击处理 |
| 推开 | 右键 | 近距离把敌人推出一小段距离，给撤退和转身留空间 |
| 冲刺 / 蹲行 | Shift / Ctrl | 在迅速转移与降低声音之间选择 |

空挥也消耗体力，轻击与重击存在清晰的收招。推开消耗较高体力，不能无限连按控制敌人。体力耗尽仍可正常走动，保留脱离战斗的机会。

初始等级使用基础扳手时，普通感染者以约 3 次有效轻击或 2 次重击倒下作为调试起点；它的危险主要来自距离与夹击。升级与换装应让同类敌人明显更好对付。头部命中优先强化失衡与反馈，不把首版做成精确瞄头才有效的战斗。

### 打击特效与手感是一套东西

| 命中对象 | 画面 | 声音与触感 |
| --- | --- | --- |
| 感染者 | 身体按受力方向偏移，符合力度的后退、失衡；少量血迹可关闭 | 接触闷响、衣料声、低频重击；攻击动作与目标受击动作短暂停顿 |
| 木柜 | 命中点出现木屑和新裂痕，达到破坏阈值后局部板材脱落 | 木材闷响、断裂声；碎屑从接触面散开 |
| 金属门、管件 | 擦痕、少量火星和灰尘，保持真实材质尺度 | 清脆碰撞、短暂金属余响 |
| 瓷砖、混凝土 | 小碎片、粉尘与贴花 | 短而硬的撞击声 |
| 玻璃柜 | 首击裂纹、破碎时碎片与落地声 | 清晰的碎裂声，同时成为高强度噪声事件 |
| 空挥 | 武器惯性与收招 | 破空声，没有命中特效或命中停顿 |

命中停顿初始尝试约 40–70 毫秒，仅影响本次武器与受击动画，不冻结整个世界。镜头短促地沿受力方向回弹，重击比轻击明显；屏幕震动强度可调，保留视野与头部晃动设置。

一次挥击对同一目标最多结算一次，命中点与挥动轨迹一致；墙壁先被击中就阻止击中墙后的敌人。划分起手、有效接触、收招阶段，避免“尚未挥到就扣血”或“已经收招还在判定”。

可破坏对象限于标记好的柜面、玻璃与少量障碍。整栋楼不做任意破坏；贴花、粒子与碎片必须有数量上限和回收时间。

## 5. 威胁：声音把搜刮和战斗连接起来

首版只制作一种感染者及一套基础动画，支持游荡、调查声音、发现玩家、追击、攻击、受击与死亡。单次通常面对一个，错误路线或连续噪声可能引来第二个。

- 感染者攻击前有抬肩、迈步和发声等提示；玩家能后退躲开，也能找机会重击或推开。
- 声音来自真实动作：蹲行和开抽屉较轻，跑步与打斗更响，砸玻璃最明显。
- 听见声音只会去声源调查，不会直接知道玩家当前位置；看见玩家后才进入追击。
- 关门与墙体影响声音传播。玩家可投瓶到走廊另一端，绕过正在调查的敌人。
- 攻击和寻路都遵守门、墙、家具的空间边界；没有隔墙扣血或突然出现在背后的增援。
- 退出视线后，敌人先搜查最后看见的位置，再逐渐放弃。首版不做无限追踪。

门口是重要的战斗空间：玩家可以守住狭窄入口，先重击逼退，再绕家具脱身。敌人同样能堵住门，迫使玩家换位。预留能侧身绕行的空间，避免角色和家具碰撞让战斗变成卡住不动。

夜晚更危险作为后续扩展。第一版不做随时间强制刷出尸潮的全局倒计时，也不因拾取目标物品就凭空刷怪。

## 6. 人物状态、升级与撤离

### 血量与即时状态

| 数值 | 作用 | 恢复与反馈 |
| --- | --- | --- |
| 生命值 HP | 受到攻击时扣除，归零失败 | 充足饱食与水分支持脱战缓慢回复；回安全屋可休整；受击方向、血条和低血量提示清楚可读 |
| 体力 | 轻重击、推开、冲刺消耗 | 停止高消耗动作后恢复；耗尽时仍能正常走路，恢复后重新使用相应动作 |
| 饱食度 | 影响持续活动与体力恢复 | 食物补充；局内缓慢消耗，短局不要求频繁停下进食 |
| 水分 | 影响体力上限和恢复效率 | 饮水补充；正常活动缓慢消耗，冲刺增加少量消耗 |

生命和体力是动态值，体质与耐力是长期属性，两者在界面上明确区分。护甲由穿戴提供，属于减伤属性，不另设一条可自动回满的护盾血条。

首版状态采用以下可解释规则，具体阈值待试玩调整：

| 状态 | 触发示例 | 效果与解除 |
| --- | --- | --- |
| 饱足 | 饱食、水分均高于 70，且一段时间未受击 | 支持缓慢回血；开始战斗或资源不足时停止，不能在连续挨打时靠吃东西抵消伤害 |
| 饥饿 | 饱食低于 25 | 体力恢复减慢；吃东西解除，不直接锁死普通移动 |
| 缺水 | 水分低于 25 | 可用体力上限暂时降低；喝水解除 |
| 力竭 | 体力耗尽 | 暂停重击、推开和冲刺等消耗动作，仍能走动；自然恢复后解除 |
| 负伤 | 生命低于 30% | 显示明显风险提示；不额外叠加减速，保留玩家撤离能力 |

增益或减益出现时，用图标加简短文字说明来源与效果。相同状态只保留一份，阈值设置小幅回差，避免数值在边界波动导致图标反复闪烁。首版饥饿与缺水主要影响作战续航，不做持续扣血和不可逆重伤链条。

### 击杀经验与升级

- 打怪是主要经验来源。经验在确认敌人死亡时结算，不按每次命中发放；同一个敌人实例只能结算一次，尸体不能继续提供经验。
- 普通感染者暂定 40 经验，1 → 2 级暂定需要 100 经验；之后每级需求逐步增加。首局击败约 3 个普通敌人能体验一次升级。强敌与更高风险区域后续提供更高奖励。
- 首次发现新区域、首次完成补给目标可以给少量经验，不能靠反复开柜或空手进出安全屋刷奖励。选择避战仍能带回物资，但成长速度慢于主动战斗。
- 升级当场增加一个可分配的属性点，显示升级提示；不强制打开菜单，也不自动回满血。点数允许暂存，玩家在安全时分配。
- 等级、经验、剩余属性点和已分配属性长期保存；首个版本先开放 1–5 级用于验证，不代表最终等级上限。

### 四项长期机能素质

| 属性 | 提升方向 | 每投入 1 点的调试起点 |
| --- | --- | --- |
| 力量 | 近战伤害、重击失衡能力 | 近战伤害约 +6%，重击失衡能力约 +5% |
| 体质 | 生存容错、生命上限 | 最大生命 +10；增加上限时不自动治疗当前伤口 |
| 耐力 | 连续作战、冲刺续航 | 最大体力 +10，基础体力恢复约 +3%；增加上限不立即补满体力 |
| 敏捷 | 转移、换位、装备切换 | 基础移动约 +2%，武器切换速度约 +5%；首版不改变挥击有效接触时间 |

基础示例为 100 生命、100 体力；上述增量均为调试参数。单项前期最多投入 5 点，敏捷带来的基础移动提升最多 +10%，保持狭小住宅内的距离判断。后续再扩展抗性、感知与专精。

角色页将总效果拆成“基础 + 加点 + 装备 + 当前状态”。来自同一维度的普通百分比加成先相加，不进行多层倍率相乘；防护与消耗减免设置上限，不能通过穿戴组合得到免伤或零消耗攻击。

可以形成四种倾向：力量配重武器、体质配防护外套、耐力配持续近战、敏捷配轻装绕行。食物与穿戴提供可更换的战术选择，升级形成长期成长；初期不锁职业，在安全屋可免费重置已分配属性，方便试不同组合。

### 成长仍需保留战斗判断

旧区域敌人不随玩家等级自动同步变强，升级后回去应能体会差异。更深区域通过新的攻击节奏、敌人组合和环境压力提高难度，再配合适量数值提升。

装备不设等级穿戴门槛：搜到好东西就能尝试。重武器仍有耗体力、收招和噪声方面的代价，穿上防护衣也仍需看敌人攻击动作。等级高并不取消墙体遮挡、攻击距离或受击硬直规则。

### 撤离、失败与保存

手电继续用于照亮柜体与走廊，作为固定探索工具随身携带；首版不消耗电池。主要补给压力集中于可食用物品和角色状态。

撤离点是出发时的安全屋门。到达后按 E 入内并收门，短暂收门过程中受击可打断；成功后把背包物资存入仓库。只有现存敌人会追来，撤离区不会生成额外敌人。

物资不够、受伤过重也允许撤回，结算显示本次收获与需求缺口，随后可以再次外出。不能通过锁住出口逼玩家继续搜刮。

首版采用宽容的失败规则：保留等级、已获得经验、已加点属性和已有仓库，恢复本次出发前的武器与穿戴。背包中的未入库物资在失败时丢失；本轮新获得的装备只有撤回入库后才成为长期装备，即使临时穿在身上，失败也不会保留。已吃掉、喝掉或投出的物品记录为已消耗，不在失败后复制返还。等级不会因为本次失败回退，玩家仍有成长收获。

旧维修存档独立保留，新玩法使用新的存档标识与版本。保存角色成长、当前状态、装备实例、背包、容器、敌人和奖励结算标记；退出再进入恢复同一次外出，不重置敌人或重复结算经验。敌人和物资刷新仅在新的正式外出或后续的区域刷新规则下发生，开关门与读档不触发刷新。

完整的按天生存、多个楼层和安全屋扩建属于后续系统。首版验证一次外出中的吃喝、穿戴、战斗升级和撤回入库，并允许保留成长再出发。结算同时显示新增物资、经验与属性变化。

## 7. 首个关卡：《断水之夜》

目标：带回至少 2 瓶水；途中能体验一次吃喝、一次武器或穿戴替换、一次击杀升级。首次体验目标约 5–8 分钟，熟悉后应更快，不用等待动作凑时长。升级和换装是体验引导，不作为撤离门槛。

### 场景范围

| 区域 | 基础与改动 | 玩法作用 |
| --- | --- | --- |
| 安全屋门口 | 利用原走廊端点，增加门和存放台 | 查看需求、人物加点、整备装备、撤离结算 |
| 302 厨房 | 复用现有厨房、柜体、水槽与锅具 | 安全的第一次拾取、生活物资、柜门交互 |
| 302 客厅 | 复用沙发、茶几、台灯，调整家具留出绕行空间 | 第一次可预见的近战，获得经验后检索尸体取得装备 |
| 公共走廊 | 复用并局部扩出错身位置 | 听声、诱导、两条退路之间的选择 |
| 303 小储物间 | 唯一新增的可进入房间；短支路连接原走廊 | 第二瓶保底水、备用饮水、高价值穿戴柜与可选冒险 |

两条返程选择由 302 原有的两个出入口与走廊构成：可以穿过客厅，也可以退回厨房入口。开发时先验证这个小回路的可行走宽度和敌人导航。

### 一次可能发生的游玩

1. 你在门口看到饮水缺口，检查生命、体力和穿戴，带扳手与手电出发。
2. 厨房有第一瓶水和能量棒。你吃下能量棒，获得短时体力恢复增益；普通柜门一次打开就能看见内容。
3. 客厅的感染者抬肩准备扑击，你后退躲开，用重击和轻击将它击败，获得经验；对准尸体按住 E 检索，再领取并换上棒球棍。
4. 303 有第二瓶水和一个存着防护外套的玻璃柜。已经可以撤回，但你希望多带一件穿戴装备。
5. 你砸开玻璃，响声引来走廊里的感染者。新武器更长、更有力，也更耗体力，需要适时推开和换位。
6. 击败本轮第三个敌人后升到 2 级。你可先存着属性点，在脱离危险后投入力量，在下次外出体验更强的重击。
7. 撤回安全屋后，水和新装备入库，经验和加点保留；下一次出发可以选择更高防护，也可以换轻装留出续航。

这是规则组合产生的示例，不要求强制按这条脚本行动。安静搜刮、清理后搜索和受伤撤回都应是有效路线。

首版内容上限：3 种可食用物、2 把近战武器和投掷空瓶、3 件可搜到的穿戴（外套、鞋、背包）、一种感染者、四项可加点属性和 1–5 级成长、约 8–10 个搜索点、一个上锁分支、一个撤离点、全图约 3 个敌人，同时近身交战尽量不超过 2 个。新增 303 前先完成现有房间的完整小循环。

## 8. 保留、改造与新增

| 现有基础 | 处理方式 |
| --- | --- |
| Godot 工程、Blender 场景、材质及许可记录 | 继续使用；导出场景时保留柜门、门等可动件，静态部分继续合批 |
| 第一人称移动、碰撞、灵敏度与视野设置 | 保留；加入冲刺、蹲行、体力、角色属性与穿戴影响 |
| 扳手模型和第一人称持物位置 | 保留；重新制作挥击、收招、推开及命中动画 |
| 原检修仪 | 退出默认持物，位置用于手电 |
| 交互射线、目标名称与提示 | 扩展成物品、容器、门和撤离交互；近战另外实现挥击范围检测 |
| 雨声、房间底噪、空间音效播放 | 保留环境层；补充近战与敌人音效，并增加供 AI 使用的噪声事件 |
| 设置与存档框架 | 沿用交互方式与文件写入基础；新玩法的数据结构单独设计 |
| 工单界面 | 改为三类物资、人物状态、装备与加点、补给需求和撤离结算 |
| 管网、阀门、浮空杯与反向水流 | 管线作为环境道具；停用维修状态与浮空效果，水流恢复自然或关闭 |
| 原维修逻辑和测试 | 留作旧版记录，不要求新模式依赖它们；新玩法按新规则验证 |

现有场景把静态几何按材质合并，不能直接把合批后的整块柜子当成可开门容器。资产构建需要先分离柜门和可破坏面板，这部分列为明确的改造工作。

新增模块：战斗与伤害、受击反馈、感染者 AI 与导航、噪声传播、三类物品与容器、背包与穿戴、人物即时状态、经验等级与属性结算、撤离与仓库状态。物品模板和已拥有的装备实例分开记录，避免同类物品共用可变状态。避免把所有新增系统继续堆入现有 `main.gd`。

## 9. 实施顺序与通过标准

| 阶段 | 交付 | 进入下一阶段的条件 |
| --- | --- | --- |
| A：打击手感样片 | 现有客厅内，一把扳手、一个敌人、一个木柜；轻重击、推开与三种反馈 | 空挥和命中明显不同；敌人受击有方向和力度；墙体遮挡正确；连续挥击不会重复扣血 |
| B：人物与成长 | 生命、体力、饱食、水分、基础状态、击杀经验和四项加点 | 吃喝和状态影响能看懂；一次死亡事件仅奖励一次；升级不强制弹窗；属性变化真实作用于移动、伤害与续航 |
| C：物资与装备 | 三类物资、第二把近战武器、穿戴槽、可开柜门、六格背包与扩容 | 拾取、吃喝、换武器、穿戴和容量变化闭环完整；装备对比准确；缩小背包不丢物或复制物品 |
| D：声音、路线与撤离 | 声音调查、投瓶、关门、双路线、303、安全屋入库 | 战斗和诱导绕行均能完成补给；可以提前撤回；没有隔墙追击、卡门或必须杀光才能走的问题 |
| E：完整短局与打磨 | 《断水之夜》、成长存档、失败重试、界面和美术统一 | 首局有升级和换装机会；关键物资可达；恢复不复制物资、重置奖励或叠加穿戴属性；成长与入库规则符合失败结算说明 |

玩法试玩还要验证：玩家能否说清“为什么再搜一个柜子 / 为什么撤回”；是否愿意再玩一轮；战斗是否有力且可控。自动测试通过不能替代这些体验判断。

首版暂缓：开放世界、多人联机、大规模尸潮、枪械弹药体系、武器耐久、复杂制作配方、基地自由建造、大型技能树、流血感染治疗链与随机生成整栋楼。基础升级加点属于首版必做内容，职业与技能树后续扩展。

## 10. 风格保持与美术重点

继续使用灰绿旧漆、蓝灰阴影、潮湿水磨石、雨窗和少量暖色应急灯。末日感来自搬空的住宅、仓促封堵的房门、散落的饮水包装和凌乱的搬运痕迹。

把制作优先级放在玩家反复近看的手、扳手、柜门、物资与感染者受击动作上。环境可以逐间精修。武器拖影与高亮命中闪烁保持克制，打击强度主要由动画、声音、接触点粒子与敌人反应共同表现。
