# 《南楼求生》装备升级与改装设计

日期：2026-09-16  
版本：v0.2，质变升级与打击感方向  
状态：已落地首轮球棍「破阵」与扳手「破势」原型；其余路线、材料经济与穿戴强化仍为设计建议。实际范围与验证见 [近战质变升级验收](../implementation/近战质变升级验收.md)。

首轮简化为安全屋免费强化单件已有武器：球棍重击击飞并撞倒后排；扳手采用「第一段斜击 → 第二段上挑 → 第三段下砸」，让一次连击就能完整体验质变。后续解锁成本与分支选择尚未接入。

上一稿以性能取舍和配件槽为主，已被用户否定。当前稿替代上一稿作为后续设计依据；旧稿仅归档留存，不继续执行其中的伤害换噪声、容量换移动惩罚和三阶段开槽方案。

## 1. 玩家应该感受到的成长

第一次拿球棍：挥到敌人身上，能看见身体顺着挥击方向折过去，听见扎实的接触声。

第一次强化：重击可以把普通感染者掀翻，立刻腾出前方空间。

第二次强化：被击飞的敌人撞倒后排；狭窄走廊成为能打出连续击倒的有利地形。

回到熟悉街区时，玩家从谨慎绕行变为主动清出道路。敌人的强度不跟着角色等级同步上涨，旧敌人用于证明成长，新挑战以后通过组合和空间增加。

每个升级节点必须回答：“现在能做出什么以前做不到的动作或效果？”节点要有独立可演示的战斗场面，主要收益在一次战斗内可见。

## 2. 四个确定的原则

1. 升级增加新能力，保留原来的基本能力；数值提高用于保证新能力真正有效。取消“升完后某项基础能力反而显著变差”的主线设计。
2. 角色获得过的强化长期保留。分支可以同时解锁，在安全屋选择当前招式或核心模式；未选分支保留进度，支持随时尝试另一种打法。
3. 招牌能力与战斗动作绑定：重击、连续轻击、瞄准射击、冲刺蹲下、推开后接攻击。优先复用现有操作，不增加满屏技能按钮。
4. 基础武器就要好用。碰撞可靠、攻击响应、命中声音、敌人受击和基本群体命中属于基础质量，不通过升级锁住。

继续保留写实旧住宅与冷峻光照。战斗在力度、速度和物理反应上作游戏化夸张；优先使用木屑、玻璃、尘土、枪口火光和敌人动作表达威力。

## 3. 首轮实施前的主要缺口

以下为设计时的代码检查记录；首轮已实现基础横扫多目标、受控击飞和倒地：

- 近战通过 sweep 返回第一个碰撞目标，横扫一次只结算一个目标。
- 敌人的受击主要由统一的 stagger 状态、位移和姿态偏移表现，死亡使用同一套动画。
- 已有短暂停顿、材质粒子、武器音效和镜头回弹，可以作为基础继续加强。
- 弩箭已有飞行和下坠，枪械已有弹匣与换弹，适合分别扩展贯穿和连射。

实施优先顺序因此改为：基础打击闭环 → 一把能产生质变的武器 → 装备成长与安全屋接入。第一轮不并行铺开大量槽位和配件。

## 4. 武器强化：解锁招牌能力

下表为完整方向；用户确认首轮同时实现球棍猛击与扳手连击，具体招式以本文开头的实施说明为准。

| 装备 / 方向 | 第一次质变 | 后续质变 | 玩家想尝试的场面 |
| --- | --- | --- | --- |
| 扳手 / 连击 | 连续轻击可接独立的第三段上挑，打断敌人并使其失衡 | 上挑命中后可立即衔接一次向下追击 | 贴身三连击，把单个敌人压制到倒地 |
| 扳手 / 突击 | 获得短距离突进重砸 | 突进命中倒地目标可触发短促的追加砸击 | 主动贴近并迅速解决落单目标 |
| 球棍 / 猛击 | 重击将普通敌人掀翻或击飞 | 飞出的敌人撞倒后排，撞墙产生追加重创 | 在走廊打出一次连锁击倒 |
| 球棍 / 横扫 | 获得更完整的横扫连段，连续攻击覆盖身前多个目标 | 连段末击扫倒近处敌群，为换武器创造空间 | 被几名普通感染者围住时主动清场 |
| 弩 / 贯穿 | 一支箭可贯穿前后排列的两个普通目标 | 近墙命中可将目标固定在墙面，形成清晰的钉墙反应 | 等敌人走成一线，一箭处理两个目标 |
| 弩 / 连射 | 一次装填后可连续发射三支箭 | 获得快速三连发模式，连续压制近处目标 | 通过连续箭击把逼近的敌人截住 |
| 手枪 / 点射 | 解锁短点射，一次扣动扳机连续发射三发 | 点射命中可打断普通敌人的冲近动作，击杀后接快速战术换弹 | 短时间内打出明确爆发，再转向下一目标 |
| 手枪 / 贯穿 | 解锁穿透普通目标的射击模式 | 要害击杀后短暂获得更快的目标转移与再次举枪动作 | 连续处理走廊中的多个目标 |

球棍基础横扫就要命中实际挥到的多个目标；横扫路线升级的是连段、覆盖方式和扫倒能力。猛击路线的第一轮目标为：招牌重击能直接解决普通单体，或将其打至可快速追击解决的状态；接触位置、剩余生命和撞击环境决定具体结果。

两条路线提供不同的强能力。获得新能力后，伤害、击退与动作衔接应一起调整到能完成招牌效果，而非让玩家看见新动画却仍需反复敲击许多次。

连射弩需要对应的新武器外观和装填动作，使用现有普通弩箭；三连射实际消耗三支箭。手枪短点射实际消耗三发弹药，并在剩余弹药不足时只发射现存数量。

霰弹枪可作为后续的新武器里程碑：近距离强烈击退、多枚弹丸打击不同部位、门口一枪清出空间。它拥有独立模型与弹药类型，不作为现有手枪的附加数值节点。爆破箭留作更后面的游戏内弹种方向，首轮不依赖爆炸系统。

## 5. 穿戴强化也增加动作能力

| 装备 | 第一次质变 | 后续方向 | 正反馈 |
| --- | --- | --- | --- |
| 防护外套 | 硬抗：一轮交战中可承受一次普通轻击，保住正在进行的重击或换弹动作 | 冲撞：冲刺中主动推撞，顶开挡路的普通敌人 | 敢于把攻击打完，能主动突破围堵 |
| 运动鞋 | 滑步闪避：快速侧移，避开已看清的扑击 | 滑铲：冲刺蹲下时铲倒普通敌人，起身接攻击 | 走位本身能制造攻击机会 |
| 背包 | 独立弹药袋：常用弹药进入专属容量，不占主物资格 | 第三个武器快挂位：近战、弩、枪可组成完整携行配置 | 少被整理背包打断，更容易连续换武器作战 |
| 固定手电 | 更清晰的远近照明配置，提升探索可读性 | 后续可做照明与持握方式变化 | 黑暗中找目标、辨认攻击动作更顺手 |

外套的硬抗只抵消一次普通受击打断，生命仍会损失；强制扑倒等强控制留待敌人系统明确后再处理。能力在脱离交战后恢复，用护具受击音和姿态表达状态。

滑步与滑铲依靠真实位移、碰撞和动作窗口，不穿墙、不穿门。滑步先验证横向躲避；滑铲作为后续独立能力，不要求同时实现翻越系统。

背包扩容可随成长一起提高，但核心奖励是弹药袋与新增武器位。弹药袋仍有清楚的容量，只有完成容器或尸体检索并领取后，弹药才进入其中。支持合并同种弹药的剩余数量，物资守恒。

穿戴升级保留已有防护、移动和容量收益，不再以扣掉容量或明显拖慢跑动抵消升级。造型随升级改变，让玩家从模型和动作认出自己的成长。

## 6. 打击感要贯穿整个命中过程

### 出手

按下攻击立即有手部动作响应；支持短输入缓冲，让下一击可以顺畅接上。轻击干脆，重击有短促且可读的准备动作。可中断时机由动作规则决定，不能靠反复取消跳过命中前摇。

### 接触

命中判定与武器实际运动对应。横扫沿挥击方向检查多个目标，目标之间按接触顺序处理。墙体和不可穿透障碍阻断后续命中，隔墙目标不会受伤。

接触瞬间同时触发武器阻力、敌人受击和分层音效。建议从轻击约 40–60 毫秒、重击约 70–100 毫秒的局部停顿开始试玩，连续命中多个目标不累计为长时间冻结。停顿主要落在攻击者武器和当前受击者，不冻结整个世界，也保持玩家转向响应。

### 敌人反应

按受击方向、位置和力量区分反应：横扫带动上半身侧转，砸击使身体下沉，上挑使目标后仰，腿部扫击导致倒地。死亡反应延续最后一击的方向与动量。

击飞撞墙要有撞击声、尘土、停顿和二次姿态变化；撞到另一个敌人时，后者也有可见的失衡或倒地。采用受控的击飞、倒地与物理混合，先保证身体不穿墙、不无限弹跳，再扩展自由布娃娃。

### 声音和画面

同一次重击组合挥动、实体接触、护具/骨骼闷响、环境回声和落地声。轻重击、击中墙面和击中敌人应能只凭声音区分。声音出现时机与接触帧一致，控制峰值和重复声音堆叠。

画面优先展示武器形变/回弹、敌人位移和环境碎屑。镜头回弹短且很快归位，准星持续可读。现有镜头晃动与少量血迹设置继续生效；即使关闭这两项，敌人动作、音效和物理反馈仍要成立。

### 击倒后的衔接

短处决和追击保持第一人称、不切镜头。允许玩家转向或结束动作，避免长时间锁住控制。击杀可恢复一小段近战体力，帮助从一次成功命中进入下一次攻击；它是战斗结算奖励，不生成地面物资。

## 7. 成长节奏：尽快尝到第一口强化

首个武器突破建议在前 5–10 分钟的目标体验内获得，这是设计目标，需以实际试玩校准。通过确定的搜索点拿到关键升级物件，带回安全屋完成短动作安装；首次路线不依赖多轮随机刷材料。

武器成长结构改为“基础能力 → 第一次招牌突破 → 同方向进阶”。配件用于解锁能力，安全屋界面直接呈现招式演示、获得的新能力与操作动作。解锁后永久记录，可换招式；世界中的手持武器必须同步显示对应外观和动作。

人物加点保留。专精优先接入连贯战斗，例如：

- 乘胜追击：击倒敌人后可以迅速接下一击，击杀恢复部分体力。
- 破阵：成功冲撞后立刻接近战重击。
- 快速转火：要害击杀后，下一次举枪或切入备用武器更利落。

这些节点提供衔接机会，效果从真实命中和击杀事件触发；重复击打尸体不累积收益。首次选择只开放与已实现动作相关的少量节点，不同时铺开庞大技能树。

## 8. 安全屋与街区服务于爽感

原先确认的长期通路和安全屋成长继续推进，但排在第一个战斗样例验证之后。

- 工作台：安装关键升级物件，解锁招牌动作；完成后立刻能进入短试用场景体验。
- 护具台：开放硬抗、滑步等穿戴能力，升级时有直接可见的外观变化。
- 整备架：保存不同武器组合，已有配件与物品自动从仓库调取，尽快开始下一轮行动。
- 永久捷径：完成探索后开放更直接的返程和进攻路线，让强化后的玩家更快进入下一场战斗。
- 后续新区域：提供新武器和下一次质变的目标；普通区域保留清怪效率提升的成长感。

物资仍分为可食用、武器、穿戴，升级物件按武器/穿戴子类管理。设施和通行物件沿用独立任务记录。所有物资来自柜子、尸体或明确的搜索来源，延续先检索后领取的方式。

## 9. 第一轮只证明一件事：这一棍足够好玩

制作一个位于现有走廊的短体验：三名普通感染者先后逼近，周围有可碎玻璃与一面实体墙。

先用基础球棍体验可靠的群体命中、方向受击、干脆的击倒和连续输入。再获得猛击强化，同样的位置一棍将前排击飞并撞倒后排，接上追击解决剩余目标。用相同敌人和场景前后对比，让质变清晰可见。

第一轮需要完成：球棍多目标挥击、普通受击与倒地、受控击飞、敌人间碰撞反应、击墙反馈、分层音效，以及强化前后的切换体验。验证时可使用内部测试入口；正式游戏中的获取随后接入搜索与安全屋，不向玩家展示调试文字。

通过这个体验后，再做弩箭贯穿/钉墙与第一项穿戴动作；然后接入安全屋、永久通路及更多成长。手枪连射、连射弩、第三武器位、霰弹枪分别推进，避免在核心打击尚未成立时同时扩展所有系统。

## 10. 判定是否成功

1. 隐去伤害数字和属性面板，玩家仍能通过动作与结果辨认强化前后。
2. 相同场景、相同普通敌人，强化后能明显缩短解决时间，并产生新的连锁结果。
3. 挥击真正覆盖到的多个敌人都有反应；障碍后的敌人不被误伤。
4. 声音、武器接触、停顿、身体反应与环境碎屑发生在同一个命中节拍。
5. 连续出手顺畅，镜头能保持目标可读，击倒后有自然的追击机会。
6. 搜尸点跟随最终落地位置；击飞、钉墙后的敌人仍有可接近的搜索交互，不能把物资卡进墙里。
7. 同一攻击或同一受击者的二次碰撞只按规则结算一次；死亡、经验与尸体物资只生成一次。
8. 贯穿的一支箭仍只产生一支可回收箭，记录在最终承载它的可检索尸体；中途经过的目标不各生成一份。
9. 保存、继续、切换区域、死亡恢复保留已解锁能力和物品消耗；空枪、尸体不能刷连击资源。
10. 游戏内继续采用无文字指引表现；能力说明放在玩家主动打开的装备与成长界面。

本次仅修订设计。上述群体击飞、贯穿、钉墙、滑步及成长能力均尚未加入当前游戏。
