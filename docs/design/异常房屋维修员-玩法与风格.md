## 1. 游戏承诺

你是空置住宅楼的夜间维修员。住户已经搬走，值班室的打印机却继续吐出报修单。

你用检修仪和扳手追踪反常的物理现象，恢复房屋的正常运转。每次修理会让一个局部空间变得可信，也让整栋楼的秘密更清楚一点。

玩家需要体验的三个时刻：

1. **发现不可能的现象**：水沿着水槽向天花板流，杯子停在台面上方。
2. **通过证据理解原因**：仪表、管线和不同房间的反应能共同解释故障。
3. **亲手恢复秩序**：阀门归位，表针回落，水滴落进水槽，杯底重新碰到台面。

首个原型的目标是让这三个时刻连成一次完整维修。

## 2. 核心循环

领取工单 → 观察现场 → 测量并定位 → 提出修理顺序 → 操作装置 → 检查连带影响 → 验收 → 回到值班区。

每一环都需要玩家做判断：

| 环节 | 玩家在判断什么 | 反馈方式 |
| --- | --- | --- |
| 读工单 | 哪个现象需要恢复，验收范围包含哪里 | 简短故障描述、房号和验收项 |
| 看现场 | 哪些物品反常，哪些仍然正常 | 水流、悬浮物、灯光、局部声音 |
| 测量 | 异常影响哪个支路，装置是否仍有负载 | 检修仪指针、方向刻度、声音频率 |
| 定顺序 | 先释放负载，还是直接调整；异常会流向哪里 | 可追踪管线、旁路接头、物理标牌 |
| 操作 | 阀门是否到位，软管是否接好，锁环是否紧固 | 手部动作、阻尼、刻度、卡位声 |
| 验收 | 原故障是否消失，相邻房间是否受影响 | 多点复测、重开水龙头、工单勾选 |

工单只描述故障与验收目标。环境负责提供解法线索，工具负责帮助验证。

## 3. 让异常有可学习的规则

本作采用虚构的“房屋校准管网”：某些检修管线负责维持局部空间的物理方向。这是游戏世界的规则，不是现实维修流程。

首关只教一种异常：**局部重力方向反接**。玩家和建筑主体保持稳定；故障支路只影响指定的小物件与水流，范围由接头和仪表读数说明。

必须保持一致的规则：

- 同一支路上的受影响物品遵循同一个方向；不会为了制造惊吓单独随机改变。
- 调整一个仍有负载的接头，会把异常转移到与它连通的相邻支路。
- 接好收集罐并打开旁路，可以让这组支路的负载逐渐释放。
- 完成泄压后再校准接头，才能稳定恢复正常方向。
- 测量结果会如实反映当前状态；操作结果能通过画面与声音复核。
- 错误操作可以在现场补救，没有一次误操作就必须重开的关卡状态。

后续才逐步探索空间伸缩、声源错位等新规则。首个原型集中验证重力反接。

## 4. 工具与交互

### 检修仪：获得证据

一台旧式手持仪表，包含方向刻度与负载表针，外观像经过改装的建筑检修设备。

- 靠近测试接点测量；离开有效距离时明确显示无读数。
- 检查水槽、相邻房间和检修口，可以比较支路状态。
- 抬起仪表时仍能看见附近环境，读数变化与物件状态相互印证。
- 显示方向与负载，不直接显示下一步解法。
- 提供可选的大字读数，避免小表盘成为阅读障碍。

### 扳手：精确改变状态

- 可以松开锁环、旋转校准接头并重新紧固。
- 按住并拖动进行转动，刻度和卡位声显示是否到位。
- 提供等价的按键操作，拖动精度不成为通关门槛。
- 工具只能作用于清楚可见的接头、螺母和检修件。
- 通用阀门、软管接口也可直接用手操作，动作与工具用途匹配。

### 现场设备：组成修理方案

首关现场提供一根引流软管和一只固定的收集罐。玩家将软管接到旁路口；接口外形、管线走向和标牌共同提示用途。

软管使用有限连接点和预设摆放状态。背包先采用固定工具加一件可携带任务物品，避免早期整理物品打断诊断节奏。

### 建议操作

| 输入 | 行为 |
| --- | --- |
| WASD、鼠标 | 走动与观察 |
| E | 查看、开门、拿取或连接现场设备 |
| 按住右键 | 抬起检修仪测量 |
| 左键并拖动，或替代按键 | 操作扳手、接头和阀门 |
| Tab | 查看工单 |
| Esc | 退出近距离操作或暂停 |

具体按键可在实现时微调。所有功能采用可重绑定的动作名称组织。

## 5. 首关：302《水不往下流》

### 工单

> 房号：302  
> 故障：厨房水流反向，台面器物悬浮。  
> 登记状态：空置。  
> 验收：厨房水流恢复正常；客厅支路无异常；检修口封闭。

目标体验时长：首次游玩约 10–15 分钟，实际以试玩结果调整。

### 空间布局

场景由一段公共走廊、玄关、厨房和小客厅组成。

- 从厨房入口就能看到向上流动的水，保证第一次异常易于发现。
- 厨房与客厅隔着敞开的门，转移异常后，玩家能立即看见或听见相邻区域的变化。
- 厨房检修箱露出两条分别通往厨房与客厅的支路，走向清楚可追踪。
- 小型收集罐固定在检修箱下方，软管挂在附近。
- 灯光引导关注操作区域，同时保留足够的环境亮度。

### 体验流程

**第一段：进入与发现。**

玩家从值班区拿到工单，进入 302。楼内只听得到日光灯和远处管道声。厨房里，一条水流从水槽附近升向天花板，一只杯子悬在台面上方。

靠近水流后，检修仪显示反向；转身测量客厅，读数正常。这建立“局部异常”的概念。

**第二段：诊断。**

沿检修管线找到打开的检修口。这里能看到一个方向接头、两条相连支路、一个旁路口和下方的收集罐。

现场铭牌提供规则提示：“带载调向将影响相邻支路。校准前接入回收旁路。”它说明工作原理，不列出逐步操作清单。

接头的方向箭头与正常方向标记相反，负载表针位于高位。玩家需要把两条证据联系起来。

**第三段：试验与修理。**

正确做法是接好软管，打开旁路，看着表针回落；随后松开锁环，把方向接头转回正常刻度并紧固，最后关闭旁路。

如果玩家先直接校准，厨房会暂时恢复，但客厅的台灯底座开始离地，检修仪能测到异常转移。玩家可以从现场继续补救，不会扣血或丢失物品。

**第四段：验收。**

关闭旁路、封闭检修口后，重新开关水龙头。水正常落下，杯子接触台面，相邻支路的台灯稳定落地。

玩家复测厨房与客厅，并在工单上确认验收。只有实际状态符合要求，工单才允许完成。

**第五段：留下下一单。**

返回走廊，打印机给出下一张工单：“401，卧室长度异常。”值班墙上的建筑图却只画了三层。

这段只是后续悬念，首个原型不包含四楼关卡。

### 修理状态与补救

| 状态 | 厨房 | 客厅 | 玩家可做什么 |
| --- | --- | --- | --- |
| 初始反接 | 水流向上，杯子悬浮 | 正常 | 比较读数，接入旁路 |
| 未泄压就校准 | 暂时恢复 | 异常转移，台灯底座浮起 | 打开已接好的旁路，继续泄压 |
| 旁路接通且打开 | 当前异常逐渐减弱 | 若有转移，也逐渐减弱 | 观察负载表针降到安全刻度 |
| 负载释放完毕 | 暂时稳定 | 稳定 | 校准并紧固方向接头 |
| 正确校准并关闭旁路 | 稳定正常 | 稳定正常 | 复测、封口、验收 |
| 未校准就关闭旁路 | 异常逐渐回到故障支路 | 取决于接头位置 | 重新打开旁路，完成校准 |
| 负载尚未释放完就关闭旁路 | 异常再次增强 | 若有转移则在相应支路增强 | 重新泄压；已完成的正确校准无需重复 |

收集罐容量覆盖本关全部负载，不会因尝试次数耗尽。罐内反馈用于表达收集过程，不引入额外容量管理。

### 防止卡关的设计

- 未接软管时，旁路无法形成通路；接口有明确反馈，不发生无提示的状态变化。
- 房间与物品始终可达，异常不会堵住唯一出口。
- 修复进度采用状态判定，不要求玩家严格按脚本顺序触发事件。
- 正确修复前不能误签工单；工单标明尚未通过的验收项目。
- 提示逐级提供：先提示看邻室，再提示比较支路，最后提示旁路与负载的关系。
- 存档点至少覆盖进屋前和完成维修后；原型阶段可提供关卡重置入口用于测试。

## 6. 冷峻悬疑的视觉基准

用户已确认整体气质，并通过概念图确认写实方向。以下内容以该图为基准，进入游戏引擎后验证实际效果。

### 建筑与时代感

一栋年代模糊的老式城市住宅。以水磨石地面、半墙瓷砖、乳胶漆墙面、铁制配电箱、木门和细管线构成空间。

生活痕迹包括杯子、水渍、墙上的旧挂钩和褪色标记。道具数量克制，每件重要物品的用途和位置都应可信。

### 造型与材质

采用写实 3D：真实住宅尺度、自然物体比例、可信的光照与材料响应。近距离可见瓷砖接缝、水迹、柜门掉漆、金属氧化、布料和手套褶皱；磨损集中在符合使用习惯的位置。模型复杂度与贴图大小按实际观看距离分配，优先保证玩家会近看和操作的工具、阀门与接头。

保持基准图中的材质关系：粗糙旧墙面、半反光瓷砖、磨损柜体、潮湿地面、带雨痕的玻璃和暗色工作手套。地面湿润只在合理区域体现，避免所有表面都像涂了亮油。

异常通过方向、距离、运动和声音表现。避免让所有异常都变成发光能量或巨大裂缝。

### 色彩与光照

| 用途 | 色彩方向 | 初始参考 |
| --- | --- | --- |
| 阴影与金属 | 蓝灰 | #27343B |
| 瓷砖与旧漆 | 褪色灰绿 | #667875 |
| 墙面与纸张 | 灰白 | #B7BDB6 |
| 标记与阀门 | 少量旧锈红 | #92574C |
| 检修工作灯 | 少量暗琥珀色 | #C99A53 |

阴雨天窗光和冷色日光灯形成基调，检修箱旁的小工作灯提供局部暖光。色号是概念起点，进入引擎后根据实际光照调整。

重要路径、接点和物件保持可读；黑暗用于建立深度，不掩盖必须操作的对象。

### 第一视角与界面

- 以自然视高和清楚的空间关系为主，镜头晃动默认很轻并可关闭。
- 下方能看到工作服袖口、手套和工具；工具不遮挡关键检修区域。
- 中心使用小型交互点，靠近有效对象才显示动作提示。
- 工单采用纸张与清晰字体结合的样式，并提供放大阅读。
- 检修仪以实体表盘为主，同时提供可选的大字辅助。
- 不同故障状态同时用形状、刻度、文字或声音表达，避免仅依赖颜色。

## 7. 声音与悬疑节奏

声音承担三项功能：空间定位、操作反馈和异常辨识。

- 正常背景：日光灯低鸣、远处管道、雨点和脚步反射。
- 异常线索：水声从头顶而非水槽传来；相邻支路发生变化时，声音位置跟着移动。
- 操作反馈：扳手咬合、锁环卡位、负载释放、杯底落在台面。
- 修复反馈：异常频率消退，恢复能解释得通的日常声音。
- 悬念：修好后出现一个克制的新事实，例如并不存在的房号。

首关以安静观察和可控操作建立紧张感。战斗、追逐、突发高音量惊吓和计时失败不进入首个原型。

### 第一版只验证

- 一段走廊、一间厨房和一个相邻小客厅。
- 一种异常、两件工具、一套旁路装置。
- 一条正确修理路径和可逆的错误操作。
- 完整的工单、诊断、修理、复测和完成流程。
- 一组能够代表最终方向的灯光、材质与声音。

暂缓整栋楼、程序生成、多人模式、复杂背包、经济系统和完整角色演出。

### 如果原型成立

后续工单可以让已学规则相互组合：

1. **走廊比建筑更长**：卷尺帮助判断空间伸缩，玩家需要找出错误的空间接头。
2. **敲门声来自空房间内部**：通过不同接点的读数和声源变化追踪故障。
3. **四楼被收进抽屉**：将空间连接规则发展成一个更大的关卡事件。

新工具在确有新判断需求时加入。维修难度主要来自规则组合与因果关系，而不是增加重复转阀次数。

## 10. 进入实现后的验证标准

以下是待测试目标，不是已有结果：

- 新玩家进入厨房后，能迅速发现向上水流和悬浮杯子。
- 无口头指导的玩家能通过测量区分厨房异常与客厅正常。
- 发生错误操作后，玩家能注意到异常转移，并有机会解释原因。
- 正确修复后，各房间的画面、声音、仪表和工单状态一致。
- 反复开关旁路、改变操作顺序或退出近距离操作，不会进入无法完成的状态。
- 玩家能辨认关键对象，并可调整镜头与文字阅读方式。
- 用首批少量试玩者的实际行为检验时长、提示和操作手感，再确定扩展方向。

## 11. 实施基准与待验证项

整体气质和写实视觉方向已由用户确认，无需重复询问相同偏好。
